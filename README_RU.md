# DAA Assignment 3

**Kuat Allazhar**

Design and Analysis of Algorithms

Для этой работы я использую Java 17. В проекте есть объединение компонент, минимальные остовные леса, компоненты сильной связности, топологическая сортировка и кратчайшие пути в DAG.

## Алгоритмы

| Задача | Реализация |
|---|---|
| `dsu` | Сжатие пути и объединение по размеру |
| `kruskal` | Сортировка рёбер по весу и объединение компонент через DSU |
| `prim` | Списки смежности и очередь с приоритетом, с запуском для каждой компоненты |
| `scc` | Косарайю: два прохода DFS и транспонированный граф |
| `topo` | DFS с тремя состояниями и обратный порядок завершения |
| `dag` | Релаксация рёбер в топологическом порядке и восстановление маршрута |

Код находится в [Algorithms.java](src/Java/Algorithms.java). Для стоимости и расстояний я использую `long`, а для DFS — явные стеки. ID рёбер сохраняют исходные позиции во входном массиве.

## Запуск

Нужны JDK 17+ и Python 3.12+. Java должна быть доступна через `PATH`, либо в `JAVA_HOME` должен быть указан путь к JDK.

```text
python tools/run.py --setup
python tools/run.py --check
```

Мои тесты, проверка маршрутов и сравнение времени:

```text
python tests/run_all.py
```

Запуск программы на сохранённом входном файле:

```text
python tools/run.py --input tests/cases.jsonl
```

## Пример

Программа читает один JSON-запрос на строку и возвращает один JSON-результат на строку.

Вход:

```json
{"task":"dsu","n":4,"operations":[[0,1],[1,2],[0,2],[3,3]]}
```

Выход:

```json
{"states":[[3,2],[2,3],[2,3],[2,3]]}
```
